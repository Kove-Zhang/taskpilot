# TaskPilot 文档资料库 (Documentation Repository)

本目录 (`doc/`) 专用于集中存放和归档 **TaskPilot 现代智能效率控制台** 的所有项目文档、操作手册、设计方案及参考资料。

---

## 📂 目录说明与管理准则 (Management Guidelines)

根据项目工程化规范，本仓库遵循以下文档存储原则：

1. **统一归档**：除了针对 GitHub 仓库主页展示必需保留在根目录下的项目介绍书 (`README.md`) 外，**所有后续新增的文档类资料（如指导手册、架构说明、设计规范、测试报告、白皮书等）均务必统一保存在本目录下**。
2. **格式规范**：优先使用 Markdown (`.md`) 格式书写，保持层级结构清晰，并结合 Mermaid 流程图或表格以提升可读性。
3. **命名清晰**：文档命名应明确反映内容属性（如：`TaskPilot使用手册.md`、`架构设计白皮书.md` 等），避免模糊命名。
