# Task Pilot

Task Pilot 是一款基于 Tauri + React 构建的现代化桌面效率工具。它能够像 Spotlight 或 uTools 一样随时唤出，利用 AI 大模型的能力，从您杂乱的文本、剪贴板、截图甚至各种文档中智能提取结构化的待办事项（To-Do），并一键同步至您的 Notion 数据库。

## ✨ 核心特性

- **🚀 黄金视窗与沉浸式高定工作平台**：
  - **1024 × 768 黄金比例底座**：全新升级桌面主视窗尺寸至经典 4:3 黄金视区（可视面积增大 64%），保持 `resizable: false` 固定精确定位，无边框透明背景设计，随用随唤。点击外部区域自动隐藏，不打扰您的正常工作流。
  - **自适应舒展容器与视觉排版**：设置面板宽度拓宽至 `820px`（视口滚动高度提升至 `72vh`），邮箱监听历史与“逐条审核模式”展示宽度扩展至 `940px ~ 960px`。多选框、服务商配置表单、邮件长文本与 Notion 属性字段完全舒展呈现，彻底消除了狭窄空间下的挤占与文本换行，为您提供顶级的空间留白与人体工学阅览体验。
- **🔄 多大模型服务商智能轮换与故障转移 (AI Failover Engine)**：
  - **多节点优先队列与连接测试**：支持在设置中同时配置多个模型供应商（如 OpenAI、Claude、DeepSeek、Ollama），通过可视化 **`↑` / `↓` 优先级排序**与独立 Switch 启用/停用，并可一键点击“测试连接”实时验证节点健康度。
  - **无感故障转移 (Seamless Degradation)**：在进行待办提取或 AI 写作时，若首选供应商遇到网络超时、`429 Rate Limit` 或 `5xx Server Error`，系统会在达到重试阈值后**自动顺位降级轮换至下一正常服务商**，保障业务不断连且不产生额外 Token 消耗。
  - **智能折叠指南**：内置渐变高亮故障转移说明指南，默认贴心折叠，随时解答多节点调优规则与安全机制。
- **📧 智能邮箱自动化与多模态图文解析**：
  - **专注式“逐条审核模式 🚀”全能化对齐**：右上角一键开启沙盒视图，时间倒序对未审邮件进行一对一流水线处理。顶格支持**多选过滤勾选框**（`☑️ 未审核` / `☐ 已审核`）；完美对齐常规明细弹窗能力——在逐条模式下具备完整的**双 Tab 导航**（📋 待办处理 vs 📧 邮件原文与图片）、**鼠标拖拽划选文字直接一键生成待办**、手动新增/编辑事项及 Notion 一键同步推送功能。支持 `Enter` / `Space` 一键标记已阅并下一条等四大人体工学快捷键。
  - **一体化扫描控制台与日志显隐底座**：在立即扫描执行期间，指示条实时显示 **[⏸️ 暂停/继续]** 与 **[⏹️ 停止]** 干预控制按钮，随心掌控任务生命周期；针对日志过长问题，新增 **`[× 收起控制栏]`** 按钮，收起后顶栏会自动唤出 dynamic 按钮 **`[📋 扫描状态/日志]`**，随时随地自由呼出。
  - **历史审核状态持久化与精细化药丸标签**：每封历史邮件卡片及详情页新增可切换的 `[ 审核通过 / 未标记 ]` 状态，操作后直接通过底层硬件加密实时持久化写入磁盘；全面重构标签 UI 为带精细图标、等高圆角的 **Pill Badge 系统**（已推送改用高辨识度 Sky 天蓝配色），彻底消除标签堆叠冲突。
  - **后端图文深度提取与附件净化**：Rust 底层 IMAP 协议解析器支持递归解包邮件 MIME 树，自动同步抓取 `text/plain`、`text/html` 正文与内嵌图片，自动过滤并剔除非文本类无关附件或二进制流，防范 Token 溢出并节省冗余计费。
  - **长链会话自动解构与折叠降噪**：针对企业常见“十几层转发、数万字堆叠”的超长邮件周报，内置兼容中英文 Outlook, Foxmail, QQ 等客户端的正则切片引擎，自动将邮件剥离为 **`latestMessage`（本次发信正文）** 与 **`historicalThreads`（往期转发回帖链）**，并在界面上方统计显示折叠释放的冗余字数。
  - **自适应图片排毒减重**：内置独立的高性能图像压缩与清洗引擎，在上传大模型前自动对大尺寸附图进行多阶二次压缩与降维，严防 Token 超限爆量。
  - **AI 权重分级与自适应摘要**：送入大模型前自动实施**权重分级提示词隔离**——将本次最新回复作为 **100% 核心权重** 置顶，往期历史回帖降格为 **20% 历史背景参考** 附后，杜绝大模型被陈年旧任务误导。
  - **1024x768 黄金视窗手风琴矩阵与人体工学工作区**：在宽阔大视区下运行的双切签导航。置顶高亮当前核心正文，下方往期引用回帖按 `#1`, `#2` 顺序以**手风琴折叠矩阵 (Accordion Matrix)** 呈现，支持点击顺滑展开与顶部一键全开/收起，让图文多列与属性表单预览彻底告别逼仄。
  - **划选转待办自动溯源与双态阅读**：在不同层级卡片中选词转待办时，系统精准捕获来源并在待办标题和备注中追加**溯源标签**（如 `[引自历史回帖 #2]`）；针对企业 HTML 邮件深色文字与暗黑底色冲突痛点，独创 **`[ ☀️ 护眼白底原貌模式 / 🌙 深色纯净模式 ]`** 实时切换，白天深夜均极致清晰！
- **🧠 深度大模型支持与“防思考”黑魔法**：完美兼容 o1、o3-mini、claude-3.7、deepseek-reasoner 等支持深度推理的模型。支持在设置中一键开启/关闭**深度思考模式**。关闭时底层会自动注入降级参数与独创的 `/no_think` 末端压制指令，极大提升响应速度并节省 Token。
- **🖼️ 视觉与 OCR 支持**：支持直接截取屏幕或粘贴图片，通过大模型视觉能力识别并提取图片中的任务信息。点击缩略图可开启高清灯箱预览，细节一览无遗。
- **📄 纯本地离线文档解析**：支持直接拖拽 PDF、Word (DOCX)、Excel (XLSX/XLS)、CSV、Markdown 及 TXT 等常见文档进行解析。所有解析逻辑（包括 PDF Worker）均 100% 本地打包执行，**无任何外部 CDN 依赖，保障数据绝对安全与隐私**。
- **📝 Notion 动态属性映射**：自动获取您 Notion Database 的所有字段（Properties）。支持您自由勾选需要同步的字段、自定义 AI 提取提示词，并通过可视化的**沙盒 UI 预览**和拖拽排序来自由拼装您的专属待办结构。
- **✨ AI 智能润色与写作**：内置 Prompt 优化助手，并在提取待办后支持基于 AI 生成项目总结、跟进邮件或行动计划。
- **⌨️ 快捷键自定义**：支持用户随时在设置中重定义全局唤醒快捷键，防止与系统快捷键冲突，并且支持一键恢复默认。
- **🕰️ 本地历史与原图追溯**：自动记录任务处理历史，不仅防丢，更支持在历史记录中重新查阅提取前的原始文本材料、多模态图文与历史截图。
- **🔒 高级安全与排错架构**：所有敏感数据采用 Rust 底层 `Aes256Gcm` 硬件加密保存在本地。同时配备了全参数透明的本地底层日志系统（Logger），为您排查大模型 API 调用问题保驾护航。
- **⚙️ 极致高阶配置与智能容错体系**：
  - **多收件箱 / 文件夹并发监听**：IMAP 监听不仅限于主收件箱，支持填入多个以逗号分隔的子目录（如 `INBOX, Work, Urgent`），后台自动顺次轮询一网打尽；
  - **智能双轨扫描时间视界**：定时后台扫信默认抓取最近 3 天（极致轻量），手动触发或首次挂载默认抓取最近 7 天（全量补漏防休假漏单）；
  - **局部自愈重试与 Token 保护阀**：内置网络异常抗抖动自动重试引擎 (`retryCount`)，并提供可选的 Token 文本截断安全阈值 (`tokenLimit` 8000/16000)，彻底堵死长文超刷防线；
  - **单属性专属微提示词 (Prompt Hint)**：Notion 属性沙盒为每一个具体字段独立提供约束文本框，完美解决复杂下拉选框 (`Select`) 枚举对齐与绝对日期 (`date`) 推导难题。

## 🛠️ 技术栈

- **桌面端核心**：[Tauri v2](https://v2.tauri.app/) (Rust)
- **前端框架**：React 18 + TypeScript + Vite
- **状态管理**：Zustand
- **样式方案**：Tailwind CSS + 玻璃拟态 (Glassmorphism) UI 设计
- **Markdown渲染**：React Markdown + Tailwind Typography
- **文件解析引擎**：pdfjs-dist (PDF), mammoth (Word), xlsx (Excel/CSV)

## ⚙️ 初始化配置

初次启动应用后，请点击界面右上角的“设置 ⚙️”按钮进行基本配置：

1. **大模型设置**：填入兼容 OpenAI API 标准的接口地址 (Base URL)、API Key 及模型名称。
2. **提取关注点**：设定您个人的核心诉求（例如：“务必提取负责人和截止时间”），或使用系统内置的 **AI 智能润色** 帮您完善 Prompt。
3. **Notion 集成**：
   - 填入您的 Notion Integration Token。
   - 填入目标 Database ID。
   - **注意**：请务必在您的 Notion 目标 Database 页面右上角的 `Connections` 菜单中，将该 Integration 添加为允许访问。
4. **系统、日志与控制**：可在此查阅或修改应用的全局唤醒快捷键（默认 `Alt+Space`），控制是否“允许大模型进入深度思考模式”，以及开启本地日志（将打印发送给大模型的全量 Payload）以便高级排查。

## 💡 常见问题与高级机制说明

- **面对数万字、几十层转发的长链邮件（如周报、跟进链），AI 会把一年前的旧待办误当成新任务吗？**
  **绝不发生**。系统底层的 `emailScheduler.ts` 在发送给大模型前，会自动通过正则切片解构邮件。在构建 AI 提示词时进行了**权重分级隔离**：
  1. 将顶部最新回复作为 `【本次最新回信 / 核心重点（100% 关注）】` 强制模型聚焦提取；
  2. 将下方万字转发链打包为 `【历史引用与转发背景（仅供参考上下文 20%）】`。
  模型不仅能精准捕获当下的真正诉求（如最新回复人提出的新意见），更能把历史长链作为上下文背景辅助理解，杜绝旧任务误提。
- **如何在核查历史回帖时快速补漏，并确保同步至 Notion 后能清晰追溯来源？**
  我们独创了**划选待办自动溯源 (Traceable Highlight-to-Todo)** 机制。如果在阅读“手风琴历史矩阵”中的第 N 封往期回帖时发现了遗漏任务，直接用鼠标选中文字并点击浮层“从划选生成待办”：
  - 系统会自动识别 DOM 来源，自动将其打上 `[引自历史回帖 #N]` 或 `[最新发信正文]` 标签；
  - 该标签将同步写入待办的标题与备注中，最终 100% 映射同步至您的 Notion Database，让团队事后审计与来源对照一目了然！
- **如果对方使用的是极特殊的邮件客户端，转发分隔线无法识别怎么办？**
  目前我们的正则库已全量覆盖 Outlook、Foxmail、QQ、163、Gmail 等中英文主流分隔线格式。即便是遇到企业自研客户端等极特殊的自定义格式，底层也拥有**极限容错降级机制 (Fallback)**：不会出现解析报错或崩溃，而是无缝降级为单片全量文本模式，并依靠内置的 8000 字智能截断与自适应分级总结算法兜底，确保稳定呈现与高可读性。
- **“护眼白底原貌模式”与“深色纯净模式”应该在什么场景下如何选择？**
  - **护眼白底原貌模式（默认）**：强烈推荐在**需要进行企业合同核实、查看红黄告警高亮、财务表格对账及复核原始商业排版**时使用。该模式 100% 还原寄件人的原生 HTML 排版，彻底解决深色底色下字体变黑隐形的痛点；
  - **深色纯净模式**：适合在夜晚或暗黑环境下舒适阅读纯文本信息。底层 `DOMParser` 会智能清洗掉固化的行内颜色和背景色，提供高对比度的暗黑沉浸式体验。
- **为什么有时候 Notion 里的“计划日期”是空的？**
  为保障数据同步的稳定性，我们内置了**防崩溃安检**。如果大模型提取出了非标准格式（如“下周”、“尽快”）的日期，系统为防止 Notion API 报错导致整批数据同步失败，会主动丢弃这些非法日期字段。建议在设置中的“个人关注方向”里，强调“所有时间必须严格转换为 YYYY-MM-DD 格式”。
- **为什么网页邮箱里整理文件夹后，老邮件又被重新抓取了？**
  底层防重复机制依赖于 `文件夹名称_邮件ID`（例如 `INBOX_123`）。根据 IMAP 协议，如果您在网页端删除了文件夹并重建，邮箱服务器可能会重置邮件 ID，导致指纹失效。如遇此情况，可前往**邮件监听历史面板**，点击“清空日志”按钮，一键重置底层索引。
- **遇到网络错误同步失败时，重试会重新消耗大模型 Token 吗？**
  **绝对不会**。目前的系统针对自动化和手动操作都实现了**快照级缓存**机制。只要大模型成功解析过一次，后续针对网络波动、Notion 宕机引起的重试，都只会发送极小数据包的纯同步请求，做到零新增 Token 开销，请放心大胆地重试。
